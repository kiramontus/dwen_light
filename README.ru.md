# DataWarehouse Engine Light version
Расширение PostgreSQL для запуска SQL, PL/pgSQL задач в фоновых процессах

> [!WARNING]
> **Early Preview / Unstable:** Приложение находится на ранней стадии разработки. Возможны критические ошибки, потеря данных и резкие изменения архитектуры и структуры объектов БД. Не рекомендуется для использования в продуктивных средах.

Описание в процессе, пока пользуемся английской версией...
